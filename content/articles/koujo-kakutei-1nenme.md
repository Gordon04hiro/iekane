- 2026年に入居した場合、申告期間は2027年2月16日〜3月15日。税金が戻る申告なので、1月から出せる
- 借入先が「調書方式」に対応しているかで、そろえる書類が一部変わる
:::

## 1年目だけは確定申告が必要

住宅ローン控除（正式には住宅借入金等特別控除）は、ローンの年末残高に応じて、所得税や住民税が戻ってくる制度です。会社員の場合、2年目からは勤務先の年末調整で受けられますが、**最初の年だけは自分で確定申告をする必要があります**。

2026年に入居した場合の申告期間は、2027年2月16日〜3月15日です。住宅ローン控除の申告は税金が戻ってくる「還付申告」なので、期間より前の1月から出すこともできます。

## そろえる書類

| 書類 | どこでもらう | メモ |
|---|---|---|
| 確定申告書 | 国税庁のサイト・税務署 | e-Taxなら画面で作れる |
| 住宅借入金等特別控除額の計算明細書 | 国税庁のサイト・税務署 | 夫婦で連帯債務なら付表も |
| 住宅ローンの年末残高等証明書 | 借入先の金融機関 | 調書方式なら扱いが変わる（下を参照） |
| 家の登記事項証明書 | 法務局 | 計算明細書に不動産番号を書けば省略できる |
| 売買契約書・工事請負契約書の写し | 手元の契約書 | 買った値段を確かめるため |
| 省エネ性能などの証明書 | 売主・建築会社 | 家の種類によって必要（下を参照） |
| 補助金の決定通知書など | 市区町村など | 補助金をもらった場合 |
| 源泉徴収票 | 勤務先 | 添付は不要。申告書の記入に使う |

### 「調書方式」の借入先なら、書類が一部変わる

最近は、金融機関が年末残高を税務署に直接知らせる「調書方式」に対応した借入先が増えています。借りるときに「住宅ローン控除の適用申請書」を出していれば、一部の提出書類が変わります。手元に年末残高等証明書が届かない場合は、借入先に調書方式かどうかを確かめてください。

### 省エネ性能の証明書が必要な家

2024年以降に入居する新築は、省エネ性能によって控除を受けられる額が変わります。たとえば次のような書類で、家の性能を示します。

- **長期優良住宅・低炭素住宅**：認定通知書の写しと、住宅用家屋証明書など
- **ZEH水準省エネ住宅・省エネ基準適合住宅**：住宅省エネルギー性能証明書、または建設住宅性能評価書の写しなど

どの書類がそろっているかは、売主や建築会社に早めに確認しておくと安心です。

## 申告の流れ

1. **書類をそろえる**：年末残高等証明書は、10月〜翌年1月ごろに借入先から届くことが多いです
2. **申告書を作る**：国税庁の「確定申告書等作成コーナー」で、画面の案内に沿って入力します
3. **提出する**：マイナンバーカードとスマホがあればe-Taxで送れます。税務署に持って行く、郵送する方法もあります
4. **税金が戻る**：e-Taxなら3週間ほど、書面なら1か月〜1か月半ほどで、指定した口座に所得税が戻ってきます。所得税で引ききれない分は、翌年の住民税から差し引かれます

## 気をつけたいこと

- **ふるさと納税のワンストップ特例は使えなくなる**：確定申告をすると、ワンストップ特例の申請は無効になります。寄附した分も確定申告で一緒に申告します。くわしくは[住宅ローン控除とふるさと納税は一緒に使える？](#a-furusato-loan-koujo)をご覧ください
- **2年目からは年末調整**：2年目以降の手続きは[住宅ローン控除の年末調整（2年目以降）](#a-koujo-nenmatsu-2nenme)にまとめています

控除を受けられるかどうかや控除額は、家の種類・入居した年・所得などで変わります。この記事は一般的な手続きの説明です。個別の判断は、税務署や税理士にご確認ください。
