# サイのまど 家とお金の相談室

住まいとお金の無料ツールと記事のサイトです。
ファイルを直して保存すると、**自動でチェック → 公開**されます。プログラムの知識は要りません。

### GitHubの画面での直し方（スマホでもできます）
1. 直したいファイルを開いて、右上の鉛筆マーク（Edit）を押す
2. 書き換えて、「Commit changes」を押す
3. 数分で自動チェックが終わり、問題がなければサイトに反映されます
   - 「Actions」のタブで進み具合が見られます。緑のチェックなら公開済み、赤の×ならどこかに書き間違いがあります（サイトは前の状態のまま残ります）

## 記事の書き方
1. `content/articles/_template.md` を開き、中身をコピーする
2. `content/articles/` に新しいファイルを作る。ファイル名は半角英小文字とハイフンで（例：`sell-tax.md`）。これが記事のアドレスになります
3. 先頭の「---」の間を埋めて、本文を書く
   - 見出し：`## 見出し`
   - 箇条書き：`- 項目`
   - 太字：`**太字**`
   - 小さな注意書き：`> 注意書き`
   - 制度の期限：`{{期限:stampUntil}}` と書くと、rules.yml の日付が入ります
   - 囲み：`:::ポイント` 〜 `:::`（ほかに `:::注意`・`:::まとめ`・`:::例 計算例：〇〇の場合`）。行の頭に「- 」を付けると箇条書きになります
   - 数字のカード：`:::数字` の次の行から「約600万円|すべて公立」のように「数字|説明」を1行ずつ書き、`:::` で閉じます
   - イラスト：先頭の「---」の中に `イラスト: buy` のように書くと、記事の見出しと一覧のカードに絵が出ます（buy・sell・souzoku・money・loan・akiya・bank・nisa・school・senior。書かなければカテゴリに合わせて自動）
   - 見出し（##）には自動で番号が付き、記事の最初に「この記事の内容」（目次）が出ます
   - 共有したときの画像（LINEやSNSに出る画像）は、記事ごとに `static/ogp/記事の名前.png` があればそれを使い、なければサイト共通の画像になります。画像はClaudeに「共有画像を作って」と頼めば作ります（`scripts/make-ogp.js`）
   - 検索結果に出すタイトルを短くしたいときは `検索タイトル:`（30字くらいまで）を書きます。書かなければ「タイトル」がそのまま使われます
   - 参考にした公的な資料は `参考:` に `- ["資料の名前", "https://…"]` の形で並べると、記事の最後に「参考にした資料」として出ます
   - 本文の途中のツールの案内は、3つ目の見出しの前に自動で入ります。場所を決めたいときは `{{ツール}}` と書きます
4. `下書き: true` のあいだは、サイトに「下書き」の印が出て、検索にも出ません。確認が済んだら `下書き: false` にすると公開されます

## アフィリエイト広告の入れ方
1. A8.net などのASPで広告に提携し、「広告リンク」のHTMLをコピーする
2. `content/affiliates.yml` を開き、該当する広告（住宅ローン比較・証券口座・一括査定・空き家買取）の「コード」に貼り付ける（`コード: |` の次の行から、行頭にスペース4つ）
3. 保存すると、記事の中の `{{広告:住宅ローン比較}}` などの場所に広告が表示されます
   - 広告が入った記事には「PR」の表示と「当サイトはアフィリエイト広告を利用しています」の一文が自動で出ます（ステマ規制への対応）
   - コードが空のあいだは、記事には何も表示されません
4. 新しい種類の広告を足すときは、affiliates.yml に同じ形で1つ追加し、記事に `{{広告:名前}}` と書きます

## AIの下書きを承認する流れ
1. Claudeが記事やデータ更新の案を作り、GitHubに「提案（Pull Request）」として出します
2. 自動チェックが走り、計算や表示が壊れていないかを確かめます（緑のチェックが付きます）
3. 提案を開き、「Files changed」で中身を読みます。直したいところがあればコメントするか、そのまま編集します
4. 問題なければ「Merge pull request」を押す → 自動で公開されます

## 広告の入れ方
- **AdSense**：審査に通ったら、`content/site.yml` の `adsense` にパブリッシャーID（ca-pub-…）を入れます。これで自動広告が使えるようになります（AdSenseの管理画面で「自動広告」をオンにし、スマホの「アンカー広告」、PCの「サイドレール」もオンにすると、両方で広告が増えます）
- **決まった場所の広告枠**：AdSenseで「ディスプレイ広告」のユニットを作り、表示される `data-ad-slot` の数字を `site.yml` の `adslots` に貼ります。枠は「記事の上・記事の中（見出し2つごと）・記事の下・ツールの下・一覧の中」の5種類で、どれもスマホ・PCの画面幅に合わせて表示されます
- **アフィリエイト**：`content/affiliates.yml` にコードを貼ると、記事の `{{広告:名前}}` の場所と、関係するツールのページの下に「PR」付きで表示されます

## 年1回の見直し（毎年3月ごろ）
`content/rules.yml` の次の項目を、最新の制度・調査結果と見比べます。
- 教育費（文部科学省「子供の学習費調査」・日本政策金融公庫の調査が新しくなっていないか）
- 児童手当の金額
- 印紙税の軽減措置の期限（stampUntil）
- 住宅ローン控除の借入限度額・控除期間（koujo）
- 買い替え特例・相続空き家の特例の期限（kaikaeUntil・akiyaUntil）
- 税率、仲介手数料の上限
- 最後に `checked`（確認した日）と `next`（次の予定）を書き換える

期限を過ぎた制度は、ツールの画面に自動で「期限を過ぎています」と表示されるので、見落としても気づけます。

## 最初の公開手順
1. GitHubで新しいリポジトリ（例：iekane）を作り、このフォルダの中身をすべてアップロード
2. Settings → Pages → 「Build and deployment」の Source を **GitHub Actions** にする
3. `content/site.yml` の `url` を取得したドメインに書き換えて保存（自動で公開が始まります）
4. Settings → Pages → Custom domain にドメインを入れ、ドメイン会社のDNSに案内どおりのレコードを追加。「Enforce HTTPS」にチェック
5. Googleサーチコンソールにサイトを登録し、`https://ドメイン/sitemap.xml` を送信

## フォルダの中身（直さなくていい部分）
- `src/js/` … ツールのプログラム（機能ごとのファイル。番号順につながります）
- `src/css/site.css` … 見た目
- `src/shell.html` … 全ページ共通のメニューとフッター
- `static/` … 共有用の画像・アイコン
- `scripts/build.js` … サイトを作る仕組み ／ `scripts/test.js` … 自動チェック
- `.github/workflows/deploy.yml` … 自動チェックと公開の設定
